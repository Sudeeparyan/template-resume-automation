# Company research (optional, for the strongest applications)

Use it to choose which true things to put first, never to add anything about the person.

1. Read the posting and the employer's own pages (careers, about, products, recent news). Note
   each source's link and the date you read it.
2. Separate what the pages say from what you infer, and say which is which.
3. Link each finding to a requirement of the job: what problem the team likely has, which of the
   person's real projects or roles is closest, and where the analogy stops.
4. Quote any permit or sponsorship wording exactly.

Never add the employer's technology to the person's skills, rename their work as the employer's,
or describe a project as if it was built for this employer. In App mode, the app's research agent
(`career ws run --kind research --job-id <id>`) sees only the posting and public sources, never the
person's profile, and saves `company-research.md` in the job's folder.
