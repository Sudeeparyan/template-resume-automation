# CV format (Ireland)

In App mode the profile's resume contract (page count, sections, paper) decides and the app
enforces it; follow it rather than this page.

| | Ireland |
|---|---|
| Called | CV |
| Paper | A4 |
| Spelling | Irish/UK English (organisation, analyse, modelling) |
| Length | 1 page for students and graduates, 2 pages with several years of experience |
| Photo, date of birth, marital status, nationality | never |
| Address | city and country only |
| Work permission | state it only as the person wrote it in their profile, only when they want it shown |

When `me/about-me.md` gives a resume length, use it.

## Sections, in this order

1. Name, then one contact line: city, phone, email, LinkedIn and GitHub or portfolio as full URLs.
2. Summary: two or three lines written for this job, only from their evidence. No "I", no clichés.
3. Skills: grouped (for example Languages, Tools, Methods), the job's must-haves they really have
   first. Only skills they stated or clearly used in a listed role or project.
4. Experience: title, employer, place, dates (the same format everywhere, for example
   "Jan 2024 - Present"), then 3 to 5 bullets for recent roles, fewer for older ones.
5. Projects: 2 or 3, each with a one-line context and 1 to 3 bullets. Say plainly when a project
   was for a course or personal, never presented as employment.
6. Education: degree, school, dates exactly as in the evidence, grade only when they gave it.
7. Certifications and awards (when they have any).

## Bullets

- Start with a strong verb: built, led, reduced, automated, analysed. Never "responsible for",
  "helped with", "worked on", "assisted in", "tasked with".
- Show what changed and how it was measured, using the person's own numbers only.
- One or two lines each. Most relevant result first inside each role; roles stay in date order.
- No filler such as "results-driven", "passionate", "dynamic", "synergy", "go-getter",
  "leveraged", "spearheaded" when nothing was led.
