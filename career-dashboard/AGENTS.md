# Profile-scoped application instructions

Read the selected profile's `data/config/profile.yml`,
`data/context/evidence.yml`, source library and unresolved questions before
using candidate facts. A profile's evidence registry governs every resume and
answer. Preserve source citations, uncertainty, team attribution and explicit
work-authorization wording. Do not turn a course or proposed project into
professional experience. New facts from the Profile page or uploads must be
reconciled into the registry before a resume uses them.

Use the selected profile's market and resume contract for each saved job.
Each market has its own location, sponsorship, spelling and paper rules; this
copy offers Ireland only (the US pack is dormant). Treat unknown authorization as a question before screening or preparing
an eligibility-dependent action. A job-specific pack needs the actual posting,
role evaluation, evidence map, current PDF and QA result. A QA pass verifies an
artifact; it does not promise an interview or shortlist.

The shared services for a profile own jobs, history, outputs, agent runs and
optional mail evidence. Never infer an application outcome from silence.
Email receipt is not a submission date. Ask for confirmation before sending
applications or outreach. The FastAPI server binds to loopback and file routes
stay within the profile. Run `python -m pytest -q` and
`python backend/scripts/validate_workspace.py` from this folder when code changes.
