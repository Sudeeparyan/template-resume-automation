# evaluate

Read _shared.md and _profile.md for the selected profile first.

Use the exact saved posting or supplied JD and the active profile. List essential and preferred requirements with source excerpts. Compare each to professional, academic or proposed evidence IDs; keep unsupported requirements missing. Check seniority, dates, market location and work authorization from the actual posting. If a fact is unknown, request clarification before treating the role as eligible. Record fit separately from document coverage.
