# batch resumes

Read _shared.md and _profile.md for the selected profile first.

Use when several exact job IDs or verified JDs need application packs. For each role, run the shared eligibility and evidence gates. Generate one isolated, market-specific resume and QA bundle per job. Respect the active profile's project and page contract. Preserve successful packs when a later one fails; report which IDs passed, failed or need clarification. Never manufacture jobs to fill a requested count.
