# Candidate framing

Read the selected profile's config, evidence registry, source library, and unresolved questions. Derive role tracks, narrative, skills, project selection, location and work authorization from that profile alone. Never carry another candidate's qualifications, projects, employers, restrictions, pronouns, dates or resume shape into this profile.

For a verified role, lead with the strongest registered professional or academic evidence and label the type honestly. Projects are chosen from resume-ready entries in the active evidence registry, up to the count required by the profile's resume contract. A project proposed for later work remains outside the resume. Preserve approved wording, team attribution and conditional claims. If the profile has no suitable project, omit that section when the contract allows it and explain the gap.

Use the selected job's market for country rules. Unknown work authorization must be clarified before an eligibility-dependent action. Do not infer graduation, professional tenure or a numeric outcome from incomplete sources.
