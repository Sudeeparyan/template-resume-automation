# generate resume batch

For each exact saved job ID, verify the posting and market, check authorization and essential requirements, research the employer and select supported evidence. Use each market's resume contract for paper, pages and projects. Build isolated job folders with JD, evaluation, evidence map, source, PDF, previews and QA. Preserve completed packs if a later job fails. Never claim submission.
