# Resume format: United States (dormant)

The US column of `.agents/skills/tailor-resume/references/resume-format.md`, kept here while the
US market is switched off. Restore it to that table when re-enabling the US.

| | United States |
|---|---|
| Called | resume |
| Paper | US Letter |
| Spelling | US English (organization, analyze, modeling) |
| Length | 1 page early career, 2 pages only with long relevant experience |
| Photo, date of birth, marital status, nationality | never |
| Address | city and state only |
| Work permission | state it only as the person wrote it in their profile, only when they want it shown |

Files are named `<First>-<Last>-Resume`.
